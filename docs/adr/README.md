# Architecture Decision Records

This directory contains the Architecture Decision Records (ADRs) for the
Arabic Conversation Analysis Engine.

## Authority

Project Charter
→ Adopted Specialized Specifications
→ ADRs
→ Implementation

ADRs may clarify implementation decisions but MUST NOT silently override
an adopted higher-level specification.

## Statuses

- PROPOSED
- ADOPTED
- SUPERSEDED
- REJECTED
